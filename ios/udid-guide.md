# 获取 iPhone UDID（Windows 可用，无需 Mac）

Ad Hoc 安装必须把你的设备 UDID 注册到开发者账号。任选其一：

## 方法一：爱思助手（最直观，推荐）

1. Windows 电脑安装爱思助手（i4.cn 官网下载）
2. iPhone 用数据线连接电脑，手机上点「信任此电脑」
3. 爱思助手 → 设备信息页面，找到 **UDID** 一栏（40 位十六进制字符串），复制即可

## 方法二：手机浏览器在线获取

1. iPhone 用 Safari 打开 https://udid.tech
2. 点「获取 UDID」→ 按提示**安装描述文件**（设置 → 已下载描述文件 → 安装）
3. 页面会显示 UDID 并自动复制
4. 用完可在 设置 → 通用 → VPN 与设备管理 里删除该描述文件

## 方法三：Microsoft Store 的「Apple 设备」App

1. Windows 商店安装 Apple 官方「Apple 设备」App
2. 连接 iPhone 后进入设备页面，**点击序列号**可切换显示 UDID
